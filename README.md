Pak-EduTool Project Details 📚
Description: An advanced EdTech platform designed for secure course management and a seamless learning experience, optimized for the Pakistani market.

🚀 Key Features
• User Roles: Separate, interactive dashboards for Students and Instructors.

• Secure Payments: Integrated local gateways (JazzCash and EasyPaisa) for course enrollments.

• QR Verification: A Secure QR-Based Result Verification System for instant certificate validation.

• UI/UX: Modern, mobile-responsive design with cinematic color grading and smooth animations.

• Course Management: Dynamic search functionality and structured learning modules.

🛠️ Tech Stack
• Frontend: React.js, Tailwind CSS

• Backend: Node.js, Express.js

• Database: MongoDB

• Authentication: Firebase Auth
